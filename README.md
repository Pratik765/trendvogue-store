# TrendVogue — Modern E-Commerce Platform

TrendVogue is a modern, responsive fashion & lifestyle e-commerce web application inspired by top storefronts.

## 🚀 Tech Stack
- **Frontend**: React 18, Vite, Redux Toolkit, React Router v6, Bootstrap, React Icons
- **Backend**: Node.js, Express.js
- **Design**: Custom Modern CSS Design System (Plus Jakarta Sans & Inter)

## 📦 Features
- 🌟 Modern responsive storefront with hero promotional banner
- 🏷️ Real-time category filtering (Men, Women, Kids, Home & Living, Beauty)
- 🔎 Instant product search and multi-option sorting (Price, Rating, Discount)
- 💖 Wishlist state toggle with floating heart icons & header counter
- 🛍️ Cart management with quantity counters and `localStorage` persistence
- 🎟️ Promo code system (`VOGUE200`) with dynamic bill breakdown
- ⚡ Skeleton shimmer loading animation
- 🔔 Toast alert notifications for cart and wishlist interactions

## 🛠️ Getting Started

### 1. Start Backend Server
```bash
cd 2-actual-backend
node app.js
# Backend runs at http://localhost:8080
```

### 2. Start Frontend App
```bash
cd myntra
npm install
npm run dev
# App runs at http://localhost:5173
```
